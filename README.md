# Canvas Privacy Anonymisation Experiment

This project evaluates re-identification risk in synthetic Canvas-style
student data.

## Privacy controls

- Removal of direct identifiers
- Generalisation of quasi-identifiers
- k-anonymity with k = 5
- l-diversity with l = 2
- Suppression of unsafe equivalence classes
- Measurement of information loss
